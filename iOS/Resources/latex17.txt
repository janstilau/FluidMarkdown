\section{Wrapped Figures}

\begin{wrapfigure}{r}{0.4\textwidth}
\centering
\begin{tikzpicture}[scale=0.7]
% Simple tree structure
\node[circle,draw] (root) at (0,0) {Root};
\node[circle,draw] (left) at (-1.5,-1.5) {Left};
\node[circle,draw] (right) at (1.5,-1.5) {Right};
\node[circle,draw] (ll) at (-2.5,-3) {LL};
\node[circle,draw] (lr) at (-0.5,-3) {LR};
\node[circle,draw] (rl) at (0.5,-3) {RL};
\node[circle,draw] (rr) at (2.5,-3) {RR};

\draw (root) -- (left);
\draw (root) -- (right);
\draw (left) -- (ll);
\draw (left) -- (lr);
\draw (right) -- (rl);
\draw (right) -- (rr);
\end{tikzpicture}
\caption{Binary tree structure}
\label{fig:tree}
\end{wrapfigure}

This text wraps around the figure on the right. The wrapfig package allows figures to be placed within the text flow, with text wrapping around them naturally. This is particularly useful for smaller figures that don't need to take up the full width of the page.

The binary tree shown in Figure~\ref{fig:tree} demonstrates a hierarchical data structure commonly used in computer science. Each node can have at most two children, referred to as the left child and right child.

Binary trees are fundamental data structures used in many algorithms, including binary search trees, heap data structures, and expression trees. The tree structure allows for efficient searching, insertion, and deletion operations when properly balanced.
