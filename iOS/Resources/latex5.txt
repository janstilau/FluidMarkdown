# 化学反应方程式

## 酸碱反应

中和反应：
$$\ce{HCl + NaOH -> NaCl + H2O}$$

$$\ce{H2SO4 + 2NaOH -> Na2SO4 + 2H2O}$$

$$\ce{CH3COOH + NaOH -> CH3COONa + H2O}$$

## 氧化还原反应

氢气燃烧：
$$\ce{2H2 + O2 -> 2H2O}$$

甲烷燃烧：
$$\ce{CH4 + 2O2 -> CO2 + 2H2O}$$

铁的氧化：
$$\ce{4Fe + 3O2 -> 2Fe2O3}$$

电解水：
$$\ce{2H2O ->[电解] 2H2 ^ + O2 ^}$$

## 沉淀反应

$$\ce{AgNO3 + NaCl -> AgCl v + NaNO3}$$

$$\ce{BaCl2 + Na2SO4 -> BaSO4 v + 2NaCl}$$

$$\ce{Ca(OH)2 + CO2 -> CaCO3 v + H2O}$$

## 络合反应

$$\ce{Cu^2+ + 4NH3 -> [Cu(NH3)4]^2+}$$

$$\ce{Fe^3+ + 6CN- -> [Fe(CN)6]^3-}$$

$$\ce{Ag+ + 2NH3 -> [Ag(NH3)2]+}$$

# 化学平衡

## 平衡常数

对于反应：$\ce{aA + bB <=> cC + dD}$

平衡常数：
$$K_c = \frac{[\ce{C}]^c[\ce{D}]^d}{[\ce{A}]^a[\ce{B}]^b}$$

$$K_p = \frac{P_{\ce{C}}^c P_{\ce{D}}^d}{P_{\ce{A}}^a P_{\ce{B}}^b}$$

## 勒夏特列原理

当改变影响平衡的条件时，平衡会向减弱这种改变的方向移动。

## 酸碱平衡

水的离子积：
$$K_w = [\ce{H+}][\ce{OH-}] = 1.0 \times 10^{-14} \text{ (25°C)}$$

pH定义：
$$\text{pH} = -\log[\ce{H+}]$$

$$\text{pOH} = -\log[\ce{OH-}]$$

$$\text{pH} + \text{pOH} = 14$$

弱酸的电离：
$$\ce{HA <=> H+ + A-}$$

$$K_a = \frac{[\ce{H+}][\ce{A-}]}{[\ce{HA}]}$$

# 电化学

## 电池反应

锌铜电池：
负极：$\ce{Zn -> Zn^2+ + 2e-}$
正极：$\ce{Cu^2+ + 2e- -> Cu}$
总反应：$\ce{Zn + Cu^2+ -> Zn^2+ + Cu}$

## 电解反应

电解氯化钠溶液：
阳极：$\ce{2Cl- -> Cl2 ^ + 2e-}$
阴极：$\ce{2H2O + 2e- -> H2 ^ + 2OH-}$
总反应：$\ce{2NaCl + 2H2O ->[电解] H2 ^ + Cl2 ^ + 2NaOH}$

## 能斯特方程

$$E = E^{\circ} - \frac{RT}{nF}\ln Q$$

在25°C时：
$$E = E^{\circ} - \frac{0.0592}{n}\log Q$$

# 热化学

## 热力学函数

焓变：$\Delta H$

熵变：$\Delta S$

吉布斯自由能变：$\Delta G = \Delta H - T\Delta S$

## 反应热

燃烧热：$\Delta H_c$

生成热：$\Delta H_f$

溶解热：$\Delta H_{sol}$

## 赫斯定律

$$\Delta H_{总} = \sum \Delta H_i$$

# 化学动力学

## 反应速率

$$v = -\frac{1}{a}\frac{d[\ce{A}]}{dt} = \frac{1}{b}\frac{d[\ce{B}]}{dt}$$

## 速率方程

一级反应：$v = k[\ce{A}]$

二级反应：$v = k[\ce{A}]^2$ 或 $v = k[\ce{A}][\ce{B}]$

## 阿伦尼乌斯方程

$$k = Ae^{-E_a/RT}$$

$$\ln k = \ln A - \frac{E_a}{RT}$$
